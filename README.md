# Cars Dealership Full-Stack Capstone

## Project Name
Cars Dealership - A national car retailer web application.

## Repository Name
xrwvm-fullstack_developer_capstone

## Description
A full-stack web application that displays dealership branches and allows
users to view and submit reviews. Built with React, Django, Node.js,
MongoDB, SQLite, and deployed with Docker and IBM Cloud Code Engine.

## Tech Stack
- **Frontend:** React, Bootstrap
- **Backend:** Django, Django REST Framework
- **Database:** SQLite (development), MongoDB (production)
- **Deployment:** Docker, Kubernetes, IBM Cloud Code Engine
- **CI/CD:** GitHub Actions
